# Sugar Guard (Python desktop)

Prosta aplikacja desktopowa (Tkinter), która pomaga zapanować nad:
- wilczym głodem,
- napadami na słodycze,
- codziennym nawykiem "cukier na autopilocie".

## Funkcje
- **Panel "Dziś"**: check-in snu, stresu, posiłków, wody, ruchu i porcji słodyczy.
- **Tryb "SOS głód"**: log impulsu + 10-minutowy timer odroczenia (urge surfing).
- **Plan osobisty**: cel, dzienny limit słodyczy i lista nawyków o największym wpływie.
- **Historia**: ostatnie impulsy + "wygrane dni".
- **Automatyczne zapisywanie danych** do pliku JSON w katalogu domowym użytkownika.

## Uruchomienie
```bash
python3 sugar_guard_app.py
```

Wymagania: Python 3.x z biblioteką `tkinter` (zazwyczaj wbudowana).

## Dlaczego to działa
Aplikacja opiera się na skutecznych elementach pracy z łaknieniem:
- odroczenie impulsu i "surfowanie na fali" głodu,
- redukcja ekspozycji na bodźce,
- stabilizacja glikemii przez regularne posiłki,
- monitorowanie wyzwalaczy i działań zastępczych,
- wzmocnienie przez codzienne małe wygrane.
