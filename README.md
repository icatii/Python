# Python

## ADHD screening app

This repository now includes a simple CLI self-screening tool:

- `adhd_screening_app.py`

### Important

This tool is **not** a diagnosis. It is only a lightweight educational screener.
It always recommends professional confirmation with a licensed specialist when needed.

### Run

```bash
python3 adhd_screening_app.py
```

### What else is needed for a real-world app

- A validated questionnaire and scoring model reviewed by clinicians.
- Privacy and consent handling for sensitive health data.
- Age-specific flows (child/adolescent/adult) and localization.
- Crisis/safety guidance and emergency resources when severe distress is detected.
- Clear referral pathways for specialist follow-up.
